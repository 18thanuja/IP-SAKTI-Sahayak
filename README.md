# 🌿 IP-SAKTI Sahayak
### AI-Powered Intellectual Property & Ayurveda Guidance Assistant

**Bridging Artificial Intelligence, Intellectual Property, and Traditional Knowledge.**

IP-SAKTI Sahayak is a multilingual, Retrieval-Augmented Generation (RAG)-based AI assistant designed to simplify access to Intellectual Property (IP) laws and Ayurveda-related regulatory information. It provides conversational answers supported by relevant source citations, helping users explore complex legal and regulatory topics more easily.

---

## 🚀 Key Features

- 🤖 **AI-Powered Assistance** — Provides simple explanations of IP and Ayurveda-related topics.
- 📚 **RAG-Based Retrieval** — Retrieves relevant information from legal and regulatory documents.
- 🔎 **Source-Cited Answers** — Helps users verify responses using supporting source documents.
- 🌍 **National & International Coverage** — Addresses Indian IP laws, Ayurveda regulations, traditional knowledge, and relevant international IP frameworks.
- 💬 **Conversational Interface** — Makes complex information easier to understand through interactive AI assistance.
- 🌿 **Traditional Knowledge Awareness** — Supports awareness of intellectual property considerations related to Ayurveda.
